P068 [style=Normal|align=None|sb=0|sa=0|line=None]:
  TEXT: Achieving long-term learning and habit goals depends on breaking an ambitious objective into small, scheduled actions and adjusting the plan when life intervenes. Conventional task trackers leave this decomposition entirely to the user, while general-purpose chat assistants produce roadmaps that remain trapped inside a conversation transcript. This project presents an AI Agent for Personal Goal Tracking, implemented as the GoalMate application, which closes this gap by coupling a tool-calling large language model with a persistent relational database and a live dashboard. When a user states a goal in natural language, the Google Gemini model, using native function calling, autonomously decomposes it into ordered milestones and date-assigned daily tasks and stores them in a SQLite database through SQLAlchemy. Eight database-backed tools let the agent read real progress, complete tasks, analyse missed work, adapt advice to the time available and replan deadlines, using a bounded multi-step tool loop. A Gradio and FastAPI interface provides optimistic task check-boxes, milestone roadmaps, an adaptive seven-day timeline, a Catmull-Rom cubic Bezier progress curve rendered as SVG, a habit-analytics Progress page and Sign Up / Log In access. All eight end-to-end acceptance tests, executed against the live database and the Gemini API, passed successfully. The system demonstrates that grounding generative reasoning in transactional data yields a trustworthy and actionable goal coach.
